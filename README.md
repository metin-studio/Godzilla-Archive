# Godzilla Arşiv

Python ve Tkinter kullanılarak geliştirilmiş masaüstü Godzilla arşiv uygulaması.

## Özellikler
- Godzilla ve kaiju kayıtlarını görüntüleme
- Arama özelliği
- Döneme göre filtreleme
- Farklı kriterlere göre sıralama
- Kaiju bilgilerini ve görsellerini görüntüleme
- JSON tabanlı veri yapısı
- Tkinter tabanlı grafiksel kullanıcı arayüzü
  
## Kullanılan Teknolojiler
- Python
- Tkinter
- Pillow (PIL)
- JSON
  
## Proje Hakkında

Bu proje, Python ile masaüstü uygulama geliştirme, veri yönetimi ve kullanıcı arayüzü tasarımı konularında pratik yapmak amacıyla geliştirilmiştir.

## Kurulum

Projeyi bilgisayarınıza indirdikten sonra gerekli Python paketini yükleyin:

```bash
pip install Pillow
```

Ardından uygulamayı çalıştırın:

```bash
python GArşiv.py
```

**Not:** Projenin çalışması için data ve image klasörlerinin proje dizinindeki yapısının korunması gerekir.

## Görsel Kaynakları

Kaiju görselleri Godzilla Card Game kaynaklıdır. Görseller bu kişisel, ticari olmayan eğitim ve portföy projesinde kullanılmak üzere kırpılarak düzenlenmiştir.
